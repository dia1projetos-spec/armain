## Próximos pasos
1. Subir a GitHub
2. Conectar Vercel al repo
3. En js/main.js, pegar tu config de Firebase
4. Subir fotos de perfumes a Cloudinary y reemplazar URLs en el array 'perfumes'

## Responsive
- Loader video centrado con object-fit:cover (funciona en móvil)
- Menú hamburguesa <768px
- Grid adaptable
